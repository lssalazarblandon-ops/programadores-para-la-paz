El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando sus credenciales. Esto permite verificar su identidad antes de darle acceso a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o acciones que no pueden estar disponibles para cualquier persona. De esta manera se protege la seguridad de la plataforma y de sus usuarios. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
