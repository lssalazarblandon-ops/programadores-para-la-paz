Sistema operativo:
Es el software que administra los recursos del computador y permite ejecutar programas y servicios. También gestiona el hardware y los procesos del sistema.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas, respuestas y comportamiento de la aplicación.

Puerto:
Es un punto de comunicación que permite al servidor recibir solicitudes. En esta actividad se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a identificar errores, monitorear el funcionamiento y realizar mantenimiento.
